# Digital Filter Designer

Interactive MATLAB App for evolutionary digital filter synthesis (FIR & IIR) using Genetic Algorithms (GA) and Particle Swarm Optimization (PSO).

##  Download Standalone Executable
You can download the ready-to-run Windows desktop app from the **Releases** section on the right.
